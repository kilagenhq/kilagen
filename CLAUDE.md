# Kilagen

Git-native, AI-first security-program framework. Two layers: `keel/` (the reusable framework) and `program/` (the instance — your organization's content, added when you instantiate).

## Orientation

| What you need | Where to look |
|---|---|
| Framework design, layout rationale, document types | `keel/content/design.md` |
| How to instantiate the framework | `keel/content/instantiation.md` |
| Compliance strategy, standards, framework mappings | `keel/content/compliance.md` |
| Lenses (alternative projections like NIST CSF) | `keel/content/lenses.md` |
| Maturity levels and graduation criteria | `keel/content/maturity.md` |
| YAML schemas for frontmatter and capabilities | `keel/schemas/` |
| Document templates | `keel/content/templates/` |

## When an instance exists

Once a `program/` layer has been added, read `program/registry.md` first — it is the authoritative index of the instance's documents, capabilities, and framework coverage. Do not rely on assumptions about what exists; check the registry.
