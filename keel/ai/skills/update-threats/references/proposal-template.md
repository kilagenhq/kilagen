## How to review this proposal

You have two paths. Pick the one that suits you.

### Path 1 — Talk to Claude (recommended; no editor needed)

Open Claude Code (terminal) or this same chat. Say something like:

```
Open evidence/threat-updates/REPLACE-DATE/proposal.md and walk me through
each item one at a time. Update the file with my decisions as we go.
```

Claude reads each item in order, summarises it, and asks you yes / no / modify in chat. It updates this file behind the scenes as you decide. When you're done, ask Claude to run the runbook in apply mode.

### Path 2 — Edit the file yourself

Open this file (`evidence/threat-updates/REPLACE-DATE/proposal.md`) in any text editor — VS Code, TextEdit, Cursor, etc. Markdown preview helps but isn't required.

**The only mechanic you need:** find lines that look like `- [ ] **Approve** — ...` and change the `[ ]` to `[x]` for items you approve. That's it.

- Each item starts with `- [ ] **Approve**` followed by an identifier (e.g. `S1`, `U2`, `R1`). The identifier is just a label so you can tell items apart — you don't write anything new there.
- Ticking is the **only required action**. You don't write a reason, a comment, or anything else.
- You can also edit body text (severity, lenses, attack vectors, etc.) — your edits are what gets written on apply. Leaving an item untouched is fine.
- You can leave a one-line `> rejected — <short reason>` note above an item you're declining, but it's not required.

### Both paths end the same way

When you're done ticking / editing, run apply:

```
Follow program/runbooks/rb-update-threat-catalog.md in apply mode
using evidence/threat-updates/REPLACE-DATE/proposal.md.
```

The apply phase reads this file in its current state, applies only the ticked items, and validates everything. **Items left unticked are not applied** — no further action needed for those.

### Why Claude Code Desktop can't edit the preview

Claude Code Desktop's markdown preview is read-only by design — it's a viewer, not an editor. Path 1 above is the intended workflow (let Claude do the file edits via chat). Path 2 works in any external editor; the file is plain markdown.
